## ✨ About the Project

A student performance analysis application developed using Python, Pandas, and Streamlit. It helps organize marks, calculate academic results, and visualize student performance through an interactive interface.

## 🚀 Features

- 📊 Interactive student performance dashboard
- 📝 Add student details and marks for five subjects
- 🧮 Automatic total, average, percentage, and grade calculation
- ✅ Pass/fail status calculation
- 🏆 Topper identification
- 📈 Class average and pass-rate analysis
- 📉 Student percentage and subject-wise charts
- 🔎 Interactive student data table
- 📁 CSV export and local data persistence
- 🛡️ Duplicate student and input validation

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| Python | Application logic |
| Streamlit | Interactive web interface |
| Pandas | Data processing and analysis |
| CSV | Local data storage |

## ⚙️ Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd Student_Marks_Analyzer_Premium_Complete
```

**2. Install dependencies**

```bash
pip install -r requirements.txt
```

**3. Launch the application**

```bash
streamlit run student_marks_analyzer.py
```

Open the local URL displayed in your terminal, usually `http://localhost:8501`.
